# Integration of a Generative AI Model into a Semantic Vector-Based Music Recommendation System

ПРОЕКТ: AndrewSound
ОПИС: Інтелектуальна система семантичного пошуку музики на основі векторних ембедінгів та ШІ.

ЛОГІКА РОБОТИ СИСТЕМИ

1. Семантичний аналіз:
ШІ Gemini перетворює текстовий запит користувача (наприклад, "музика для драйву") у математичний вектор. Це дозволяє системі розуміти "сенс" запиту, а не просто шукати збіги в словах.

2. Векторний пошук:
Алгоритм HNSW миттєво знаходить у базі треки, які за своїми характеристиками (векторами) знаходяться найближче до запиту користувача.

3. Результат:
Користувач отримує персоналізований список пісень, які ідеально підходять під його настрій або опис.

ІНСТРУКЦІЯ З ПІДГОТОВКИ ТА ЗАПУСКУ

КРОК 0: Налаштування API ключа
З міркувань безпеки файл конфігурації .env не зберігається в репозиторії.
1. У папці server знайдіть файл .env.example.
2. Скопіюйте його та перейменуйте на .env.
3. Відкрийте .env та вставте ваш GEMINI_API_KEY.

КРОК 1: Наповнення бази даних (Seeding)

Перед першим запуском сайту необхідно завантажити музику та згенерувати AI-вектори.
1. Відкрийте термінал у папці проекту.
2. Перейдіть у папку сервера: cd server
3. Запустіть команду: npm run seed
(Кастомний скрипт для автоматичного збору даних з Deezer API та їх семантичної індексації через Google Gemini AI. Створює базу з 200 треків та векторний індекс для пошуку)


КРОК 2: Запуск проекту через Docker
Після того, як база готова, запускаємо сам сайт:
1. Поверніться в корінь проекту.
2. Виконайте команду:
docker compose up --build
3. Відкрийте браузер: http://localhost:3000
